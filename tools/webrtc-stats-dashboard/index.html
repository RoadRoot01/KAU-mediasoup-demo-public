SFU PROBE(대역폭 탐색 더미 트래픽)란 무엇인가?

실제 영상/음성이 아닌, 네트워크 가용 대역폭(BWE) 한계를 능동적으로 측정하기 위한 mediasoup SFU의 메커니즘입니다.

SSRC: 1234 고정
1. 전송 목적

유저 트래픽이 적을 때는 네트워크가 여유로운지 나쁜지 판별할 수 없습니다. 따라서 SFU가 "화질을 더 높여도 안 끊기는지" 간을 보기 위해(probe) 의도적으로 전송합니다.

2. 패킷 특성

사람의 미디어가 들어있지 않은 순수 제로 패딩(Zero Padding) 데이터이며, WebRTC 클라이언트는 이를 디코딩하지 않고 전송 지연 및 손실만 측정(TWCC/REMB)합니다.

3. 대시보드 분리 이유

이 트래픽을 일반 피어 스트림과 합산하면 가짜 트래픽 스파이크가 발생하므로, KAU 대시보드는 이를 시스템 오버헤드로 완전 격리했습니다.

ProbationGenerator::ProbationGenerator()
{
    // Trick to only fill the padding with zeroes once.
    if (mustInitializePayload)
    {
        std::memset(ProbationPacketBuffer, 0x00, sizeof(ProbationPacketBuffer));
        mustInitializePayload = false;
    }

    // Create the probation RTP packet.
    this->probationPacket.reset(
        RTP::Packet::Factory(ProbationPacketBuffer, sizeof(ProbationPacketBuffer)));

    // Set fixed codec payload type (127).
    this->probationPacket->SetPayloadType(ProbationGenerator::PayloadType);

    // Set fixed SSRC (1234).
    this->probationPacket->SetSsrc(ProbationGenerator::Ssrc);

}
