# mediasoup-demo-app

React + Vite frontend client for [mediasoup-demo](https://github.com/versatica/mediasoup-demo).

## Installation

```sh
npm install --legacy-peer-deps
```

## Running the Application

### 1. Production Preview Mode (Recommended)
Builds the optimized production bundle and runs Vite preview. This has significantly lower CPU and memory overhead than the dev server.

```sh
npm run start:prod
```

### 2. Development Mode
Runs Vite development server with Hot Module Replacement (HMR).

```sh
npm start
```

## Default Configuration & Features

* **Default Room:** Automatically connects to room `'test'`.
* **Microphone:** Enters the room with microphone muted (`off`) to prevent sudden audio feedback. Users can unmute at any time with a single click.
* **Auto-popup Disabled:** Starting the dev server will not automatically open multiple browser windows.
* **LAN / Mobile Access:** Binds to `0.0.0.0:5555` over HTTPS. Other devices on the same Wi-Fi can connect via `https://<YOUR_LOCAL_IP>:5555/`.

## Query Parameters

You can customize parameters directly via the URL:

| Parameter | Type | Description | Default |
| --- | --- | --- | --- |
| `roomId` | String | Room ID to join | `'test'` |
| `displayName` | String | Participant display name | Autogenerated |
| `mic` | Boolean | Microphone state on join | `false` (muted) |
| `webcam` | Boolean | Enable webcam on join | `true` |
| `forceH264` | Boolean | Force H.264 video codec | `false` |
| `forceVP8` | Boolean | Force VP8 video codec | `false` |
| `forceVP9` | Boolean | Force VP9 video codec | `false` |
| `forceAV1` | Boolean | Force AV1 video codec | `false` |
| `forcePCMA` | Boolean | Force PCMA audio codec | `false` |
| `preferLocalCodecsOrder` | Boolean | Prefer browser's codec order over server's | `false` |
| `info` | Boolean | Show detailed media transmission info | `false` |
| `stats` | Boolean | Show WebRTC stats panel | `false` |
